# Checklist de acessibilidade

Estado atual: VALIDADO parcialmente no Power BI Desktop em 24/08/2026.

- [x] Contraste do tema e das dez páginas revisado visualmente.
- [x] Severidade representada por texto além da cor.
- [x] Alt text descritivo em todos os visuais informativos.
- [x] Ordem de tabulação lógica e determinística.
- [x] Navegação por ações principais testada por teclado.
- [x] Títulos descrevem a pergunta respondida.
- [x] Tabelas equivalentes disponíveis nos visuais relevantes.
- [ ] High contrast testado.
- [x] Bookmark, navegação, voltar e reset testados por foco/teclado.
- [x] Conteúdo essencial disponível sem tooltip.
- [x] Foco nativo visível nas ações.
- [x] Dez layouts mobile verificados no editor de telefone.
- [x] Tabelas usam cabeçalhos claros e ordenação previsível.

Evidências: `screenshots/desktop-contact-sheet-final.png` e `screenshots/mobile-contact-sheet-final.png`.

Limitações: high contrast permanece pendente; leitores de tela podem anunciar controles de modo diferente e devem ser retestados no ambiente final.
