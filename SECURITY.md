# Política de Segurança

## Escopo

Este repositório contém exclusivamente dados sintéticos e artefatos analíticos. Não envie credenciais, tokens, `.env`, bancos reais, logs privados, endereços pessoais ou evidências operacionais.

## Relato responsável

Abra uma issue sem incluir segredos nem dados pessoais. Para uma vulnerabilidade que exija detalhes sensíveis, use um canal privado disponibilizado pelo mantenedor no GitHub.

## Controles do projeto

- Seed fixa e identificadores fictícios.
- Validação automatizada de padrões de segredos e PII.
- CI sem credenciais e sem dependência do Power BI Desktop.
- Contrato de integração limitado a campos analíticos seguros.
